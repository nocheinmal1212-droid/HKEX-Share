## Limits and next boundary

The host enforces bounded prerequisites, occurrence membership and known conflicts; it does not
certify arbitrary natural-language entailment or independently select a complete contributor set.
The summary vocabulary is intentionally narrow. Unknown subtotal scopes and associated prose lose
operational coverage rather than receive inferred relationships. Inline-cell notes, external notes,
extractor association errors and broader vocabulary need separate source review and contracts.
Shared-unit optionality does not resolve unknown numeric prerequisites or permit calculation.

The v1 replay pin is intentionally environment-specific, including Python/dependency bytes and
original selected source descriptors. A different installation must supply the verified environment
or undergo an explicit migration review; it cannot relax hashes. The launcher is replay-only, not
a v1 dispatch route. Current code and the installed package have separate new bindings.

No implementation choice remains blocked by the subtotal or replay questions. Independent semantic
acceptance remains a separate open decision. Any future live confirmation needs separately frozen
bindings, expectations, selected cases and an explicitly authorized budget. This work authorizes
no live batch, numerical planning, arithmetic, OCR, model selection or research-role changes, and
does not claim future plans/findings isolation from today's empty downstream outputs.
