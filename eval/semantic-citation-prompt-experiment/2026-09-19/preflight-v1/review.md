# Same-agent inspection after offline tests

This is an implementation inspection by the implementing agent, not independent review or owner
approval. The review covered treatment construction, deadline ownership, call admission, immutable
completion binding, role/file isolation, evaluator separation and fail-closed launch behavior.

* **Experimental control:** A's runtime snapshot is byte-identical to the current source/schema
  inventory. B/C/D differ only in operation identity and appended prompt; an AST comparison confirms
  all remaining semantic code is identical. Each arm has the same context, source gate, schema and
  host analysis. Both roles have equal semantic payloads and distinct attempt identities. D contains
  the exact two single-factor blocks. No baseline formatting preamble was introduced.
* **Aggregate accounting:** two metadata reservations precede eight fixed role pairs. Counts and
  conservative cost are cumulative, not reset per arm. Both route validations must succeed before
  the first completion; metadata failure stops without replacement. Each reserved request is checked
  against the frozen role request after source reprojection. The full canonical reservation is
  $14.710160 within a proposed $16 ceiling. The 18-call schedule implies exactly eight completions
  per role and keeps total before period_groups in each arm.
* **Deadline and cancellation:** the launcher starts one clock before its supervised binding check,
  and passes that same clock into the experiment. All slot subprocesses inherit the experiment's
  owned session. Transport and consumer waits use remaining time; frozen transport code also checks
  immediately before its HTTP boundary. The supervisor owns executor shutdown and descendants and
  accounts for receipt publication/cleanup inside the total ceiling. Normal and interrupted runs
  both clean up. The parent reads the proposal from the bounded checker's returned result instead
  of doing an additional file read after the check.
* **Primary isolation and persistence:** primary consumption occurs before waiting for research.
  Consumers use the unchanged guarded source/primary-only read set and no supplied credentials.
  Six-file attempt bindings and original invalid-answer rejection remain intact. Cancellation tests
  preserve committed primary and incomplete research; separate reruns retain genuinely partial
  response and annotation files without false completion. Fixed-primary zero-call replay with
  perturbed research must reproduce annotation and provenance bytes exactly.
* **Observation:** evaluator and accounting code are never imported by a writer. The observer denies
  network and runs after cleanup. It preserves separate schema/host/contributor/state/citation and
  persistence outcomes. The unit-plus-lease counterexample passes host/citation checks but fails exact
  contributor comparison. Missing slots remain in the denominator; no candidate is repaired.
* **Approval gate:** hash checks bind the corrected deadline/transport path, each snapshot inventory,
  dependencies/interpreter, requests, expectations, schedule and checker itself. Default readiness
  and unused output are required. The launcher checks before accessing the sole key entry. Its
  missing-key rehearsal must stop before output creation. No .env or real credential access occurs
  in this preparation.

## Corrections and limitations recorded during preparation

The first rehearsal's fixture assumed an entirely empty interpreter environment. Python/macOS adds
LC_CTYPE and __CF_USER_TEXT_ENCODING; the fixture now permits only those names in its explicitly
empty supplied environment. The initial failed transcript/artifacts remain, followed by six passing
tests. No live transport was used. The preparation estimate initially used compact JSON; it was
corrected before rehearsal/freeze to the runtime's indented canonical encoding. Runtime reservation
and the corrected proposal agree exactly.

The result collector initially required identical provenance across two separate executions. That
expectation was wrong: immutable completion markers include each execution's timestamps/timing, so
their bound hashes legitimately differ. Annotation bytes and every other provenance field matched.
The corrected invariance experiment replays one fixed primary completion with perturbed research,
preserving all original bytes. A subsequent collector used the wrong location for observation
reports; its failure is retained and the final follow-up reads the actual path. These reporting
interruptions do not change the passing runtime tests or repair a historical result.

The input guard is not a hostile-code sandbox. Single observations per arm/case/role cannot separate
all provider revision, cache, order or stochastic effects. The reverse arm order balances positions
between cases, not every confound. All authored successes test infrastructure only; a prompt benefit
remains unobserved. The existing two cases cannot establish model abstention judgment quality.

Decision: the bounded development pilot may proceed only after the final freeze checker passes
and the owner explicitly approves its new digest and 18-call/900-second/$16 budget. No production
prompt migration, repaired historical pass, numerical acceptance or milestone completion is approved.
